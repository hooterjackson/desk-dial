## (a) Summary: r3.1 matches our plan
Hold 4 = 1.0 s with tap on release. Hold spaces are Home / Recently Added + Playlists / explorer / Up next. Home domain swap
copy `Knob sets brightness`/`Knob sets volume`. Lights-domain Home screens (`LIGHTS`, `Hall · 62% · 3200 K`, `Lights off` /
`Tap 4 to turn on`). Warm hold arc. Button 3 source toggle, crumb `MUSIC › PLAYLISTS`, explorer same-item round trip. Tracks
whole queue (clamped, 4 plays the focused row, stays on Tracks, Navigator centred on focus, `Skip to`/`Back to`/`Now`). Paused
keeps art. Idle only for nothing loaded. Area-wide lights with averages over on-lights. Snapshot on All off. Settings with
address, token, area (default Hall), Test connection and live lists. Unfilled Lights arcs off, warm-white button LEDs, green
paused Play.

## (b) Where r3.1 differs from the plan: values and copy to adopt
1. **Knob turns affect only the lights that are on** and set them all to one absolute value (avg ± detent). From all off, a turn
   turns every available light on at ≥ 1 %. Target on-light entity_ids, not `area_id` (Job A/C).
2. Temperature average rounded to **100 K**. Off state shows the last level. Turn on restores the snapshot only if the set of
   lights is unchanged, otherwise all on (Job A/C).
3. Adjusted title = area name `Hall` (not `Focus · adjusted`) (Job A/B).
4. Navigator hold row: chips `1 Home`, `4 Knob to lights` / `4 Knob to music` / `4 Queue` / `4 Play next`, filling with
   progress. Key 4 no longer highlights on press (Job A).
5. Tracks LCD status `Skip to {n} / {T} · 4 plays` / `Back to …` in green. Navigator `{n} / {T} · Press 4 to play`. Success
   `Playing {n} / {T}`. Deny at now `Turn to browse the queue`. No duration column. Seek keys `Cancel … Set … Play` (Job A/B).
6. Recently Added LCD status gains the artist: `{i} / {n} · {artist}`. Toggle resets the index to 0 and shows `Favourite
   playlists`/`Recently Added` for 1.2 s. Entering from Music always opens Recently Added (Job A).
7. Button-3 icon = `listMusic` in both sources, lit amber (`act`) + LED warm 0.9 in Playlists (plan said `playlists`/`clock`)
   (Job B).
8. Hold ring visible only after **15 %** of the hold (150 ms). Landing flash 450 ms (Home) / 600 ms (queue) (Job B).
9. Paused art at **0.45** opacity (Job B).
10. Up next hold on the playing row → deny `Already playing` (Job A).
11. Settings: Save gated on a successful Test. Address/token edits reset the status to `Not tested since the last change` (Job C).

## (c) New in r3.1 that we did not ask for
